# PRODUCT.md — @zfuzz/mcp

## Product Purpose

Security copilot for AI coding agents. Gives Cursor, Claude Code, Codex, Gemini CLI, v0, Lovable, and every major AI agent real SAST scanning, secret detection, dependency auditing, and threat modeling directly in the IDE. Built in Rust. Sub-millisecond latency. 100% local, zero cloud, zero cost.

## Users

- **Primary:** Developers using AI coding assistants (Claude Code, Cursor, Codex, Gemini CLI) who want security scanning without leaving their editor.
- **Secondary:** Security engineers evaluating lightweight, agent-native scanning tools.
- **Tertiary:** Open-source contributors and DevSecOps teams looking for free, local-first alternatives to Snyk/Semgrep.

- Glassmorphism cards with blur effects

- Overly animated pages with parallax and scroll-jacking

## Strategic Principles

1. **Show, don't tell.** Conversation examples > feature lists. Show the tool working in real agent dialogues.
2. **Credibility through specificity.** "441 SAST rules" > "comprehensive scanning". Numbers earn trust.
3. **Developer-native.** Terminal commands as CTAs. Monospace where it matters. No marketing fluff.
4. **Editorial warmth.** Cream palette, serif display type, generous whitespace. Premium without being cold.
5. **One install command.** The entire value proposition collapses to `npx -y @zfuzz/mcp`. Make that copy-paste irresistible.
